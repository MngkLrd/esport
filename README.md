# ESPORT AI Manager

AI-first single-player esports management game prototype.

The project explores a deterministic management simulation with a separate generative narrative layer: roster building, training, scouting, contracts, morale, chemistry, matches and procedural media stories.

> This is an original prototype inspired by the management-game genre. It does not use Counter-Strike, Valve, real-team, real-player, skin or tournament IP/assets.

Development happens on feature branches and lands through pull requests.
