## 2. Ключевое для переделки HOME

Подтверждены следующие реальные компоненты:

- `/basic/autorun.sh`: условно запускает `/basic/app_man` с конфигурациями `am_config` и `am_start.ini`.
- `/basic/am_config`: содержит определения Sony DockUI, Netflix, Amazon Ignition, Cobalt, YouTube, GloboPlay и других приложений.
- `/basic/am_start.ini`: содержит `dtv_app_mtk` (`/basic/dtv_svc`), `html5ui` (`/_3rd/cobalt/cobalt`), `browser_base` и DRM/streaming службы.
- `/basic/keymap_tv.ini`: содержит связь ROOT_MENU с DockUI.
- `/3rd/sony/sony_dockui/launcher.bin`: отдельный бинарник штатного launcher в `3rdp` (125 080 байт).
- `/basic/DockUI.xml/DockUI.xml`: есть старые команды запуска меню, браузера, Netflix и Opera TV Store; это не доказательство того, что этот XML управляет текущим Sony HOME в одиночку.

**Архитектурный вывод:** менять весь Linux не нужно, если удастся заменить или перехватить HOME на уровне `app_man`/DockUI, сохранив `dtv_svc` и системные OSD. Однако реального механизма передачи фокуса и HOME в прошивке ещё не реализовано и не проверено на железе.

## 3. Что потенциально можно облегчить

| Компонент | Статические сведения | Предварительное решение |
|---|---|---|
| **Samba TV / ACR** | `/3rd/samba`, CID client, relay agent, ACR-настройки; отдельный интерфейс согласия с кодом Mixpanel | **Приоритет аудита 1**. Сначала проверить фактический статус и автозапуск, затем исследовать отключение |
| **GloboPlay** | Запись `start_self=true` в `am_start.ini`; присутствует в `coexist_set` нескольких других сервисов | **Приоритет аудита 2**. Изучить, можно ли убрать автозапуск без нарушений TV и запуска приложений |
| **Amazon Ignition** | Отдельное приложение в `am_config` и около 57 МБ распакованных файлов | Сначала скрыть плитку; отключение только при отсутствии зависимостей |
| **Vudu / WASU / Opera TV Store** | Имена присутствуют в части конфигураций и DockUI XML | Удалить из нового HOME, не стирать бинарники до проверки |
| **Cobalt/YouTube** | Отдельный Cobalt в `3rd2`, сценарии HTML5UI в `am_start.ini` | **Сохранить**: требуется YouTube и возможно часть оболочки |
| **Browser Engine + Opera** | Крупный комплект библиотек, включающий DRM-окружение | **Сохранить** для браузера и совместимых WebApp |
| **Netflix + Widevine/PlayReady** | Подтверждены штатные компоненты | **Сохранить**, иначе рискуем сломать видеосервисы |
| **`dtv_svc`, модули, EPG, звук, INPUT, OSD** | Присутствуют в загрузочной конфигурации | **Неприкосновенны** |

**Критически важно:** размер файлов на накопителе не равен потреблению RAM или CPU. Сведения `start_self=true` отражают конфигурацию пакета, но не подтверждают реальный процесс на текущем включённом ТВ.

### Samba TV: подтверждения и ограничения

- Есть `/3rd/samba/cidclient` и `/3rd/samba/start_samba`, связанные с ACR.
- В `/3rd/sony/samba/v1.0.9-sony.mtk.mtk/index.html` присутствует `mixpanel.init`.
- `/3rd/samba/enable_samba.sh` настраивает состояние ACR через `acrsetting.xml` в записываемом разделе.
- **Заводской файл по умолчанию** `/3rd/samba/default_setting.xml` содержит `enabled=false`.

Это подтверждает наличие функционала аналитики/распознавания контента в пакете, **но не доказывает, что он включён на пользовательском экземпляре телевизора**, передаёт данные или сейчас расходует процессор. Актуальный `/3rd_rw/samba/acrsetting.xml` находится в отдельном записываемом разделе и в данном OTA-пакете отсутствует.

## 4. Следующая техническая задача

1. Сохранить неизменённую оригинальную прошивку и проверить путь полного бэкапа/восстановления устройства.
2. На реальном телевизоре получить перечень запущенных процессов, RSS/CPU и актуальные параметры ACR. Без этого удалять службы нельзя.
3. Выяснить, кто владеет обработчиком HOME: `dtv_svc`, `app_man`, `sony_dockui` или их комбинация. Подтвердить работу физических клавиш.
4. Собрать *отдельный обратимый* launcher-layer для HOME. Все системные кнопки и OSD остаются собственностью Sony.
5. Исследовать NFSB / проверку целостности: изменение SquashFS делает исходные хэши недействительными. Просто перепаковать ZIP недостаточно. Способа безопасной установки модифицированного образа пока нет.
6. Только после трассировки и на резервной аппаратуре начинать отложенный запуск/отключение необязательных компонентов.
