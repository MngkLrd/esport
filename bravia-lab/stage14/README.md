# BRAVIA HOME v14 — Native Product Iteration

**Target:** Sony KD-55XG7096, non-Android Linux. Original owner's firmware v8.931-1000 was audited in previous stages; this stage improves only **author-written HOME source code** and does not modify or distribute the manufacturer's firmware.

## Что улучшено

- Новый нативный экран 5×2 с 10 плитками, выразительным управлением с пульта, отдельной картой телевидения и нижним доком. Отрисовка через простые DirectFB-совместимые графические команды, без видео-заглушки.
- Состояния сервисов `APP_UNKNOWN`, `APP_READY`, `APP_UNAVAILABLE` (признаки устанавливает только будущий подтверждённый Sony-host, в текущем коде по умолчанию **все неизвестны**).
- Недоступные приложения не отправляют запрос на запуск. Неизвестные могут быть направлены на проверяющий host только при его наличии; отсутствующий host означает понятную ошибку, а не сообщение об успешном запуске.
- `last_dispatched_app` меняется **только после того, как тестовый host подтвердил приём команды**. Это НЕ подтверждение, что приложение открылось или заработал DRM.
- Информативный экран недоступности/ошибки запуска. Управление BACK/HOME и исходные системные key pass-through сохранены.
- Визуальная совместимость с форматами 1280×720, 1920×1080, 1366×768, 1024×768, 640×360.

## Запуск проверки

```bash
cd bravia-lab/stage14 && ./run_tests.sh
```

Нужны `gcc`, `make`, `clang`, `ld.lld`, `readelf`, Python 3. Для `build_preview.py` дополнительно нужен Pillow. Тест `make adapter-test` использует **специально написанный DirectFB-мок**, а не настоящий бинарный ABI Sony.

**Выход:** `build/BRAVIA_HOME_v14_ARMv7_ET_REL.o` — ARM32 объект для дальнейшей линковки, не исполняемая программа. `BRAVIA_HOME_v14_INTERACTIVE_PREVIEW.html` — автономная клавиатурная симуляция, где изображения кадров взяты из реального C99-командного рендерера. Пометки доступности Netflix/КИОН в демо специально придуманы для проверки состояний, к реальному телевизору отношения не имеют.

## Что не реализовано

- Подключение настоящего `libapp_client.so`, DirectFB Sony / управление нативной поверхностью и реальное чтение сервисного каталога.
- Доказанная установка собственного ARM ELF на защищённую Sony Linux.
- Восстановление после повреждения разделов, штатная подпись прошивки, проверка на физическом Sony, воспроизведение потоков и DRM.

**Не прошивать архив на телевизор и не пытаться устанавливать ET_REL объект через USB.** Наша задача на этом этапе — закончить качество дизайна и безопасную логику до решения вопроса установки.

В GitHub core находится в соседнем каталоге `../native_core`, а локальный ZIP содержит самодостаточную версию со всеми файлами внутри.
