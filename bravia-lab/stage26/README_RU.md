# BRAVIA Stage 26 — настоящий Sony HOME, адаптер совместимых сервисов

**Телевизор:** KD-55XG7096, оригинальная прошивка `8.931-1000-4.000-0000`.
**Основная разработка:** замена списка приложений внутри существующей HOME Sony, сохранение родных «Каналов», «Носителя» и «Установок». Это не дополнительное меню браузера.

## Основное открытие

В оригинальном разделе прошивки `3rd2` обнаружен полноценный заводской интерфейс `cobalt/content/web/html5ui/` с `allappsmodule.js`, `channelsmodule.js`, `recordmodule.js`, `mediamodule.js`, `settingsmodule.js` и `homeuiapi.js`. В нём `HomeuiInterface.LaunchApp` действительно вызывается двумя способами: с зарегистрированным Sony `service_id` и с объектом `uri`. Наличие этих вызовов не гарантирует успешного открытия произвольного URL, поддержки современного веб-плеера или DRM на физическом ТВ. Версия оригинального HOME: `2.0.32.27052021`.

Это отдельная реализация HOME на встроенном Cobalt, поставляемая *самой Sony*, а не внешняя надстройка. В прошивке также остаётся ARM `sony_dockui/launcher.bin`, а реальный сценарий передачи фокуса между ними требует теста на устройстве.

## Что разработано

- `source/bravia_catalog.js`: десять приложений в нужном порядке, собственные локальные значки, подбор точных записей по **настоящему** Sony BIVL; если родного приложения нет, URL через тот же штатный `HomeuiInterface.LaunchApp({uri})`; нет подставных service_id. Имя «YouTube Kids» не принимается за «YouTube»; неоднозначный результат отбрасывается.
- `source/patch_original_home.py`: **строго версионированный офлайн-патч** двух заводских HTML5UI-файлов, без изменения исходников. Создаёт накладку `index.html` + `allappsmodule.js` + `bravia_catalog.js` + 10 значков. Требует owner-extracted файлов, SHA-256 которых совпадают с v8.931. Не перепаковывает Sony OTA.
- `source/tv_live_trial.py`, `source/ram_hook.js`: **обратимый тест в оперативной памяти настоящего Sony Cobalt HOME через отладочный порт 9224**, только если порт доступен в локальной сети и Sony принимает DevTools-команды. `--probe` не выполняет JavaScript. Можно отменить через `revert` или перезагрузку.
- `source/run_windows.py` + `START_WINDOWS_TEST.bat`: управление тестом с компьютера на Windows, без ввода команд TV через USB.
- `source/make_icons.py` и `assets/*.png`: десять собственных 190×190 PNG. При RAM-тесте картинки передаются как локальные base64 data URI, поэтому не требуется физически записывать значки в TV.
- 14 JavaScript-тестов и 8 Python-тестов. Плюс проверен настоящий оригинальный `homeuiapi.js` во внутренней среде с подставленным Sony-хостом.

## Как попробовать НАСТОЯЩИЙ HOME Sony без прошивки

1. Открой заводской HOME на телевизоре. ПК и ТВ должны быть в одной локальной сети.
2. На ТВ в «Настройка сети → Просмотр состояния сети» узнай IPv4 (например, `192.168.1.50`).
3. На Windows распакуй данный ZIP и запусти `START_WINDOWS_TEST.bat`. Нужен Python 3.
4. Введи IP телевизора. Программа проверит **только** штатный DevTools-порт `9224` из оригинального `am_start.ini` и удостоверится, что это именно `file:///html5ui/index.html`, а не другой сайт.
5. Если HOME найден, установи пакет `websocket-client` на ПК (`py -3 -m pip install websocket-client`, только один раз), выбери `2` и подтверди `YES`. Это меняет **только переменные текущего HOME в RAM**. Не перезаписывает прошивку.
6. Если изменения видны, попробуй OK на КИОН и RUTUBE. Результат может быть ошибкой DRM/устаревшего движка — зафиксируй текст ошибки.
7. Для отмены запусти `.bat` заново, выбери `3`. Перезагрузка или перезапуск Cobalt HOME тоже отменяет RAM-патч.

**Если порт 9224 недоступен**, данный способ не работает на твоём конкретном телевизоре. Не открывай порт 9224 в интернете и не меняй скрытые загрузочные настройки ради этого теста.

## Два режима подключения сервиса

| Приложение | Режим при наличии записи в BIVL | Если нет родной записи |
|---|---|---|
| Кинопоиск | Родной клиент | Официальный сайт (эксперимент) |
| Иви | Родной клиент | Сайт (эксперимент) |
| START | Родной клиент | Сайт (эксперимент) |
| Netflix | Родной клиент | Сайт (эксперимент) |
| YouTube | Родной клиент | ТВ-страница YouTube (эксперимент) |
| RUTUBE | Родной клиент | Сайт (эксперимент) |
| Media Station X | Родной клиент | Официальный сайт MSX (эксперимент) |
| Al(co)pac | Только при наличии отдельного точного клиента | **Не определён формат совместимого клиента** |
| Браузер | Родная браузерная запись | Базовый сайт (эксперимент) |
| КИОН | Родной клиент | Официальный сайт (эксперимент) |

Ни одна из веб-версий не считается «установленным приложением». Для видеоклиентов обязательны отдельные проверки поддержки кодеков, TLS, D-pad, логина и DRM. Отсутствие портированного клиента не скрываем под чужим названием.

## Офлайн-патч заводских ресурсов

При наличии локально распакованного каталога **оригинального** `cobalt/content/web/html5ui`:

```bash
python source/patch_original_home.py --original-html5ui /PRIVATE/cobalt/content/web/html5ui --output /PRIVATE/bench-overlay
```

Накладка содержит только изменённые файлы и собственные значки; остальные файлы заводского HOME (изображения, шрифты, канал/медиа/настройки) должны оставаться оригинальными. Накладка не обладает подписью Sony, не является `PKG` или `OTA` и **не должна отправляться на телевизор через USB-обновление**. Мы не копируем проприетарные файлы Sony в публичный архив или GitHub.

## Системная нагрузка / приватность

Наш новый каталог не добавляет собственных сетевых трекеров, опросов и фоновых таймеров. Но отключить Samba/ACR, GloboPlay или браузерные подсистемы можно только после измерения реального состояния ТВ; иначе рискуем сломать зависимости каналов, YouTube и авторизации. Статические `start_self=true` не дают цифр CPU или RAM.

## Остаточный блокер

Постоянная установка всё ещё требует способа записи в защищённый раздел NFSB/dm-verity с проверкой целостности либо поддерживаемого динамического загрузчика/пользовательского каталога. Этот ZIP — **готовый к безопасной попытке RAM-теста на реальном заводском HOME, но не инсталлятор Sony**.
