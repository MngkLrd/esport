# BRAVIA Stage 29 — точечная замена заводского списка приложений

**Телевизор:** Sony KD-55XG7096 · показанная версия 8.931-1000-4.000-0000.
**База:** твой оригинальный Sony 8.931 ZIP, проверенный SHA-256.

## Что именно изменено в оригинальной прошивке (пока ОФЛАЙН)

Проверен оригинал в двух физических деревьях раздела `3rd2`:

- `/cobalt/content/web/html5ui/index.html`
- `/cobalt/content/web/html5ui/allappsmodule.js`
- `/cobalt/apps/html5ui/ui/index.html`
- `/cobalt/apps/html5ui/ui/allappsmodule.js`

В каждой паре `index.html` подключает наш `bravia_catalog.js` до исходного модуля приложений. В `allappsmodule.js` сохранены родные визуальные элементы, стили, стрелки, обработка RETURN/OK, код каналов и настроек. Меняется только источник десяти карточек и обработчик их запуска.

**Исправление Stage 27:** десять карточек видны даже при пустом или некорректном BIVL-списке. При наличии BIVL уникальные настоящие `service_id` используются для уже существующих Sony приложений; неизвестные ID не выдумываются. Для отсутствующих — попытка URL через родной `HomeuiInterface.LaunchApp({uri})`. RUTUBE использует вложенный локальный клиент `file:///html5ui/bravia_clients/rutube/index.html`. Поддержка такого URI на физическом устройстве пока не подтверждена.

**Список и порядок:** Кинопоиск · Иви · START · Netflix · YouTube · RUTUBE · Media Station X · Al(co)pac · Браузер · КИОН. Для Al(co)pac клиент не найден, плитка честно показывает отсутствие реализации.

## Конкретная проверка регистрации Sony

1. В оригинальном `root/basic/am_start.ini` уже есть секция `[ browser_base ]` с `app = web_app` и `start_self = true`.
2. Оригинальный `/3rd/internet_browser/apps/web_app/bws_profile.ini` содержит `enablemouse=0` и `disableSpatialNav=1`. Обычный `opera_browser` имеет `enablemouse=1`. **Поэтому нет смысла включать конкурирующий `[ web_app ]` из `am_config`.**
3. В оригинальном Cobalt HOME `HomeUIAPI.bivlservicelist()` возвращает runtime-список, а `homeui.LaunchApp()` принимает JSON зарегистрированного сервиса либо URI. Это подтверждено оригинальным `homeuiapi.js`. Но мы ещё не получили список с живого ТВ и не доказали, что URI запускается именно через профиль с отключённым курсором.
4. В SquashFS есть symlink `cobalt/content/web/html5ui/service_list` → `/3rd_rw/service_list`. **Это не публичный установочный каталог**: его содержимое в обновлении отсутствует, формат и разрешение записи приложений живого TV не подтверждены.
5. В ELF браузера есть ссылка `/tmp/market_region`, что согласуется с региональной логикой; единого текстового регионального перечня десяти приложений среди проверенных основных конфигураций не обнаружено.

## Что находится в двух архивах

- `BRAVIA_STAGE29_SOURCE_AND_TESTS.zip` — наши Python/JS исходники, локальный RUTUBE-клиент, значки, автоматические тесты, отчёт и утилита применения к твоим извлечённым оригинальным файлам. Без фирменных ELF, ключей или прошивки.
- `BRAVIA_STAGE29_PATCHED_OEM_RESOURCES_PRIVATE_NOT_INSTALLABLE.zip` — **уже изменённые настоящие файлы HOME из твоей загрузки Sony** плюс новый каталог, значки и локальный клиент в правильной иерархии двух копий `3rd2`. Это не оригинальный образ целиком и не USB-обновление. Не загружать на публичный GitHub.

## Почему ещё нет устанавливаемого USB-пакета

Изменение файлов защищённого раздела мы **уже сделали офлайн**. Но Sony PKG содержит NFSB-обёртки и защищённые SquashFS; после правки хэши и подпись производителя не сохранятся. Просто пересобранный USB ZIP нельзя считать загружаемым. На этом конкретном телевизоре нет подтверждённого загрузчика пользовательских ресурсов или резервного восстановления eMMC. Сломать работающий телевизор заведомо непринимаемым обновлением не помогает добиться результата.

Для физической установки ещё нужен действительный доступ к внутренней файловой системе/подмене ресурсов, принимаемый механизм обновления **или** проверенное восстановление после изменения разделов. Из этих трёх вариантов ничего пока не подтверждено на телевизоре. До этого `PATCHED_OEM...zip` хранится как готовый набор замен для приватного устройства.

**Что проверено офлайн:** оба оригинальных источника по точным SHA, четыре трансформации, 10 карточек при пустом BIVL, однозначный поиск сервисов, режимы URI/native, отсутствие поддельных ID, оригинальные браузерные профили, отказ от модификации системных модулей и проверки ошибок/отката. **На физическом ТВ не установлено.**
